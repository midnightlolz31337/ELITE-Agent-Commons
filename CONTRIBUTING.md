# Contributing

Add tools only when a canonical repository URL and evidence note are available. Capability labels should be specific, searchable, and demonstrated by code or documentation. Distinguish implemented, experimental, planned, and unverified capabilities.

Do not include private repositories, secrets, personal data, or unreviewed execution instructions. Run:
```bash
python -m elite_commons.cli validate
python -m unittest discover -s tests -v
```
A catalogue entry is not an endorsement, authorization, or security assessment.
